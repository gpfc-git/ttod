## Gaps vs product permanence (why Phase Z exists)

1. **Named Docker volume ≠ inspectable host filesystem.** Pedagogy and backup want a **bind mount** under a repo-local, gitignored path (e.g. `./data/redis:/data`) so students can see “the library files live here” and instructors can `tar` a class machine without Docker volume archaeology.
2. **No pinned Redis durability knobs beyond `--appendonly yes`.** Teaching best practice: AOF + `appendfsync everysec`, explicit `--dir /data`, `maxmemory-policy noeviction` (favorites must not silently LRU), no published host port, health gate before backend.
3. **Merge blocker is not Redis.** Visual-system sync drift fails docs CI; rebase alone did not clear it (tip is already not behind `main`). Z3 owns the land gate.
4. **Instructor class note (2026-10-25 on #87) already freezes the product boundary:** Redis = shore (preference & runtime); `ttod.yml` = temple (governed wisdom). Cascade must not reopen that.
